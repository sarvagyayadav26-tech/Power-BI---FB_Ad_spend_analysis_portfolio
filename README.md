# FB Ad Spend Analysis – Power BI

Power BI dashboard for analyzing Facebook ad performance across accounts, campaigns, and ad sets.

### Key Analysis
- Ad spend and clicks
- Impressions and reach
- CTR and CPC
- Account & campaign performance
- Campaign running duration
- Ad set efficiency and performance
- KPI and metric breakdowns

### Tools
- Power BI
- DAX
- Data Visualization
- Marketing Analytics
